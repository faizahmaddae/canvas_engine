### P1 text-tool:commit-contract-inconsistency [ux, high]
Four different commit/cancel contracts across text surfaces
Content editing is modal with real commit/cancel (cancel reverts everything). Dock sheets are live-instant with NO cancel (undo is the only escape; the ✕ just closes). The All-fonts sheet is modal but commit-on-tap with no live preview — its own barrier comment claims 'the user must keep seeing the live font change behind the sheet' yet nothing changes until the sheet pops. Viewport model: ViewportState{scale, translation, userAdjusted} (value-carried intent). Panel reflow: dock lives in Scaffold.bottomNavigationBar (EditorToolDock: fixed 80/64dp chip strip + AnimatedSize 240ms expanded zone), so the canvas pane genuinely shrinks — panels never occlude the canvas; LayoutBuilder re-triggers fit/preserve every animation frame. Repaint economics: pan/zoom re-composites the board through its boundary; per-layer boundaries prevent cross-layer re-raster (keyed against raster-cache aliasing). ### state-history
Document state: `DocumentController` (document_controller.dart, 157 ln) owns `EditorDocument` + a private `HistoryStack` (limit 200 entries, 256 MB byte budget, 64 B/entry overhead, 1 s live-merge window — engine_constants.dart:89-114). `execute/undo/redo` bump `documentCommitVersionProvider`, the commit-only signal watched by autosave, EditorScreen's lifecycle pump (editor_screen.dart:94) and the undo/redo buttons (1494). All ~30 editor providers are global non-autoDispose Notifiers; `resetEditorEphemeralState` (editor_lifecycle.dart:36-53) hand-resets 7 of them at project boundaries.

Commands: pure `apply/invert(before)/mergeWith/estimatedByteSize` (editor_command.dart). Coalescing exists in three flavors: (a) `live:true` flag gating mergeWith (image border/shadow/adjust/vignette/stack-mask, shape fill/stroke/radius, canvas background); (b) unconditional same-field-shape merge (UpdateTextCommand, UpdatePaintStyleCommand — no live flag); (c) no merge at all (SetLayerTransformCommand, SetLayerOpacityCommand — callers commit once per gesture). CompositeCommand threads inverse state correctly (transform_commands.dart:196-208).

Preview→commit patterns per tool (the core inconsistency):
- Transform gestures: `InteractionController` (1875 ln) publishes `liveTransform`/`groupLive` on its own state, zero doc writes mid-gesture, one SetLayerTransformCommand (or Composite) on release, diffed against the document with 0.25 px epsilon. Lifecycle listener cancels on external mutation; state cleared before execute.
- Text: `LiveOverlay` staging. `beginStyleDrag/endStyleDrag` wraps slider drags → overlay replaceLayer per tick, ONE UpdateTextCommand{content,style,transform} on release. Add/edit typing = one overlay-staged session → single AddLayer/UpdateText commit (text_tool_controller.dart:698-1158). Typing never produces N steps.
- Layer opacity: overlay preview onChanged, single (composite for multi) SetLayerOpacityCommand onChangeEnd (layer_opacity_control.dart:85-120). Model pattern.
- Image/shape/canvas-bg sliders: `execute(live:true)` on EVERY onChanged tick (image_adjust_body.dart:134-217, shape_style_body.dart:93-121) — committed doc mutates at 60 fps; merge keeps one undo entry but every commit bumps commit-version, resets autosave (1.5 s) and journal (750 ms) debounces, and rebuilds every committed-doc watcher. No onDragStart/End used despite EditorSliderRow supporting it.
- Paint: stroke drafts are widget-local `PaintDraft` → one AddLayerCommand on release (paint_gesture_surface.dart:136); style sliders execute per tick with unconditional merge (paint_size_sheet.dart:112).
- Crop & mask-edit: draft-first modal sessions, one Composite/SetStackMaskCommand on Done, prior-selection restore (crop_controller.dart:248-343, mask_edit_controller.dart:173-215).

Undo granularity: 1 gesture = 1 entry for transforms/text/opacity/crop/mask/paint-strokes. Image/shape slider drags = 1 entry only if pauses < 1 s; discrete taps in text/paint merge with a same-shape neighbor < 1 s apart (see problems). Two-finger tap = undo, three = redo (editor_canvas.dart:354-380).

Persistence: `AutosaveController` listens to commit version; project-store write debounced 1.5 s, only for saved projects (rule 1), thumbnailVersion 0 invalidation; `EditJournal` WAL debounced 750 ms, atomic tmp+rename, per-project file + reserved 'draft' slot; cleared on clean autosave/session end, flushed inline on pause (autosave_controller.dart:129-178). Recovery compares resolved-canonical JSON (project_recovery_service.dart:31-71). Viewport persists separately per project in SharedPreferences (project_viewport_store.dart).

Ephemeral vs document state is cleanly separated (selection, editing target, viewport, tool sessions in own Notifiers). Dock mode resolution is a boolean priority cascade over 7 tool controllers in editor_screen._resolveDock:430-470; the intended `ToolbarController`/`ModeId`/`EditorMode` orchestrator (toolbar/application+domain) has zero consumers. `DocumentController.liveReplace` is deprecated dead API.
